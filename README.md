# Adelaide Tambo Public Library
## Digital Visitor Registration System

**Project status:** Planning  
**Project type:** Web-based application  
**Frontend:** Flutter Web (proposed)  
**Backend:** Node.js + Express + TypeScript (proposed)  
**Database:** PostgreSQL (proposed)  
**Repository:** `adelaide-tambo-digital-register`

---

## 1. Project Overview

The Digital Visitor Registration System aims to replace the paper-based visitor register currently used at Adelaide Tambo Public Library with a digital solution.

The system will record daily library visits, maintain historical visitor records and generate accurate statistical reports for library management and submission to head office for reporting and audit purposes.

The application is intended to run primarily on the library's iPad.

## 2. Project Objectives

- Replace the paper-based visitor registration process.
- Digitally record visitor information and purpose of visit.
- Maintain daily, monthly and yearly visitor statistics.
- Allow authorised staff to retrieve historical records.
- Generate downloadable reports for submission to head office.
- Protect visitor information and maintain reliable records.
- Provide a simple, accessible interface for library visitors and staff.

## 3. Proposed Visitor Information

The registration workflow is expected to support:

- Initials and surname.
- Number of visitors.
- Study, reading and research.
- ICT facilities: internet, gaming and typing.
- Library use: book borrowing, booking and other approved services.
- Date and time of registration.

The final fields and categories will be confirmed with the supervisor.

## 4. Proposed System Features

### Visitor registration
- Digital visitor registration form.
- Activity and service category selection.
- Submission confirmation.
- Clear the form after each registration.



### Audit and data protection
- Reliable record storage.
- Controlled correction of records.
- Traceable administrative changes.
- Approved backup and data-retention procedures.

### Head office access
- Downloadable reports for submission.
- Direct head office access if approved by the supervisor.
