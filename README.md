## Proposed System Features

### 1. Digital Visitor Registration
A web-based registration form accessible on the library's iPad, allowing visitors to register their visits electronically.

### 2. Automatic Statistics
The system will calculate visitor counts and other statistics that can be derived from registration data. Additional reporting figures may require administrator input or integration with existing library records.

### 3. Administrator Authentication
Only authorized administrators will be able to log in and access the administration dashboard.

### 4. Administrator Dashboard
A secure dashboard displaying daily, monthly and yearly statistics, subject to confirmed reporting requirements.

### 5. PDF Report Generation
The administrator will be able to generate and download PDF reports based on the library's approved reporting template.

### 6. Historical Records
The administrator will be able to view statistics and reports from previous reporting periods.

**Note:** These features are proposed and subject to confirmation by the library supervisor and relevant stakeholders.
